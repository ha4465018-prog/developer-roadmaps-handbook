## 📖 Overview

Create interactive 2D and 3D video games using Unity (C#) or Unreal Engine (C++), covering physics, shader programming, multiplayer networking, and AI.

## 🛠️ Essential Skills & Tooling

Mastery of these foundational and specialized skills is required for competitive roles:

- **Unity (C#)**
- **Unreal Engine 5 (C++)**
- **3D Math & Shader Programming**
- **Game Physics**
- **Multiplayer Networking**

## 🗺️ Step-by-Step Learning Progression

### 🟢 Phase 1: Foundations & Core Principles (Beginner)
Focus on core fundamentals, language fluency, and core computer science prerequisites:

- [ ] C# Programming for Unity or C++ for Unreal
- [ ] 2D/3D Game Math (Vectors, Quaternions, Matrices)
- [ ] Game Engine Basics & Asset Pipelines

### 🟡 Phase 2: Applied Engineering & Systems (Intermediate)
Build production architectures, understand frameworks, and work with data pipelines and systems:

- [ ] Game Physics, Animation State Machines, Particle Systems
- [ ] Shader Programming (HLSL/GLSL)
- [ ] Game AI & Pathfinding

### 🔴 Phase 3: Advanced Architectures & Production Mastery (Advanced)
Scale systems, solve complex edge cases, optimize performance, and achieve industry leadership:

- [ ] Multiplayer Network Synchronization (Photon / Unreal Networking)
- [ ] Console Optimization (PlayStation, Xbox, Switch)
- [ ] Lead Game Engine Architect
