# Contributing to Developer Roadmaps Handbook

Thank you for your interest in contributing to the **Developer Roadmaps Handbook**!

This project is a community-driven open-source effort maintained alongside [careers.codes](https://www.careers.codes) to provide up-to-date, actionable technical roadmaps for developers worldwide.

## How Can You Contribute?

1. **Keep Tools Updated:** Suggest new, production-tested libraries, tools, or frameworks.
2. **Add Project Ideas:** Provide high-signal portfolio project prompts that hiring managers value.
3. **Refine Learning Steps:** Improve clarity, logical sequence, or learning efficiency.
4. **Fix Errors:** Spot typos, broken links, or outdated terminology.

## Pull Request Guidelines

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Create a Feature Branch:** `git checkout -b update/ai-engineering-roadmap`
3. **Make Atomic Changes:** Keep edits focused on specific roadmaps or categories.
4. **Follow Markdown Conventions:**
   - Preserve clean table formatting
   - Keep GitHub checkbox items (`- [ ]`) actionable and clear
5. **Submit a Pull Request:** Explain the rationale behind your additions or updates.

Thank you for helping developers navigate modern computer science and software careers!
